# Invitation

Reusable online invitations with event content stored separately from templates. The default template, Olive Motion, combines Olive Garden’s imagery, ivory and olive palette, and typography with Vintage Blue’s layout and interactions. Vintage Blue is a motion invitation: a cover with an arch portrait, an opening scene that pulls back over a toile landscape while palms and flowers grow in, then scroll-revealed sections for the couple, countdown, schedule, love story, gallery, live stream, gift accounts and guest wishes. The earlier template, Olive Garden, is an Indonesian wedding invitation with an animated cover, countdown, story, ceremony and reception details, calendar links, an interactive gallery, RSVP, and opt-in music.

## Run locally

Use Node.js 20 or newer.

```sh
node build.mjs
python3 -m http.server 8000 --directory dist
```

Visit http://localhost:8000/ or add `?to=Ibu%20Dewi` for a personalized greeting. The recipient parameter personalizes the page and does not authenticate guests.

## Reuse a template

1. Copy `events/ayu-raka/` to a new event slug. Edit `wedding.js` and replace the files in its `assets/` folder. The sample couple, photos, and wedding details are fictional.
2. Run `node build.mjs <event-slug> <template>` with `olive-motion` (the default), `vintage-blue`, or `olive-garden`. Deploy the contents of `dist/` to a static web host. Build and deploy each wedding separately.
3. Set `demo: false` for a real wedding. This disables browser-local demo RSVP. Set `contactEmail` to offer direct email confirmation. A shared RSVP endpoint must be connected before the form can collect guest responses.

Set each event’s optional `startsAt` and `endsAt` to ISO 8601 timestamps with explicit offsets for the countdown and calendar links. The countdown targets the earliest scheduled start.

Use `attendanceNote` to explain which events guests are invited to. For a real event, set `mapPin` to the verified entrance coordinates in `latitude,longitude` format. Without a pin, the link searches Maps by name and address.

Vintage Blue and Olive Motion also read the optional fields `shortDate`, `quote`, `inviteLine`, `couple[].instagram`, `streamUrl`, `giftAccounts`, `giftAddress` and `closing`. Olive Motion’s scene layers can be regenerated with `python templates/olive-motion/tools/draw.py` (requires Pillow). Vintage Blue’s illustrations are generated by `templates/vintage-blue/tools/`. To swap in painted versions, see `templates/vintage-blue/ASSET-PROMPTS.md`.

The Betawi Motion template now lives in its own repository: https://github.com/imamnrchls/betawi-motion

Templates live in `templates/<template-id>/`. A template can define its own layout and styles while consuming the same event data. The GitHub repository is public. Keep guest lists, RSVP records, and other private event data outside it.
